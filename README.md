# FastExpress

Proyecto integrador de la asignatura Calidad de Software para desarrollar un modulo de cotizacion de envios y descuentos.

## Componentes

- `backend/`: API REST desarrollada con Python y FastAPI.
- `docs/`: especificacion tecnica y documentacion del proyecto.
- `PROYECTO_INTEGRADOR.pdf`: enunciado original de la actividad.

El frontend se incorporara posteriormente dentro de `frontend/`.

## Backend

Las instrucciones de instalacion y ejecucion para macOS, Linux y Windows se encuentran en [`backend/README.md`](backend/README.md).
