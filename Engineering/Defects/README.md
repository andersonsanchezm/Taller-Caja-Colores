# Gestión de defectos

Un defecto describe una diferencia reproducible entre la especificación y el comportamiento observado.

## Severidad

- **Crítica:** impide usar el sistema o compromete datos.
- **Alta:** falla una función principal sin alternativa aceptable.
- **Media:** afecta una función secundaria.
- **Baja:** problema visual, textual o de baja afectación.

## Estados

`Nuevo`, `Confirmado`, `En progreso`, `Resuelto`, `Listo para retest`, `Cerrado`, `Reabierto`, `No reproducible`.
