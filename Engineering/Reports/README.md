# Reportes de ejecución

Cada ciclo debe crear una carpeta con el commit, ambiente, resultados, evidencias y defectos.

```text
Engineering/Reports/
└── ciclo-YYYY-MM-DD/
    ├── resumen.md
    ├── backend.md
    ├── frontend.md
    ├── defectos.md
    └── evidencias/
```

Resultado permitido por caso: `Passed`, `Failed`, `Blocked`, `Not Run`.
