# Testing — dobles y datos reutilizables

Esta carpeta contiene mocks, factories y datos reutilizables por las pruebas. No contiene pruebas ejecutables ni código de producción.

```text
Testing/
├── backend/
│   └── mocks.py
└── frontend/
    └── apiMocks.js
```

Las pruebas se mantienen en `backend/tests` y `frontend/src/**/*.test.js`.
